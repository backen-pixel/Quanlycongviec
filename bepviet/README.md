# Bếp Việt — website giới thiệu & bán hàng tủ bếp

Frontend tĩnh (React + Vite + Tailwind v4), tách hoàn toàn khỏi giao diện quản lý ERP.

| Lệnh | Việc |
|---|---|
| `npm install` | cài phụ thuộc |
| `npm run dev` | chạy dev (http://localhost:5180) |
| `npm run build` | build ra `dist/` |
| `npm run preview` | xem thử bản build |

Trang: `/` (trang chủ) · `/san-pham` · `/lien-he`.

Triển khai: xem [DEPLOY.md](./DEPLOY.md).
