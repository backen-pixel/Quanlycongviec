Chuỗi quyết định
  1. Short-circuit: platform_admin / isAdminLike → cho phép
  2. Module xưởng: production_* / logistics_*
  3. user_has_permission RPC + ecosystem unit BFS
  4. FE gate: RequireCrmElevated · RequireExecutive · RequirePlatformAdmin
