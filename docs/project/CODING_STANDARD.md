## 1. Stack bắt buộc

| Lớp | Chuẩn |
|---|---|
| Backend | Express 5, Node ≥18, CommonJS `require`, entry `backend/src/server.js` |
| Frontend | React 18, Vite ESM, Tailwind v4, entry `frontend/src/App.jsx` |
| DB | Supabase PostgreSQL, **không ORM**, client `config/supabase.js` |
| Auth | JWT `localStorage` + `middleware/auth.js` |
| RBAC | `middleware/newPermission.js` → RPC `user_has_permission` |
| Realtime | Socket.IO (+ Redis optional) |
| UI text | **Tiếng Việt** |
| Deploy | Render; BE serve `frontend/dist` |

### Lệnh

```bash
cd backend && npm run dev     # :4000
cd frontend && npm run dev    # :5173 proxy /api
```

## 2. Quy ước nghiệp vụ (bắt buộc)

| Chủ đề | Đúng | Sai |
|---|---|---|
| Lead/Deal | `crm_leads.type` = lead\|deal | Bảng `leads` riêng |
| Stage order | `order_index` | Cột `order` |
| Deal↔Project | `project_id` + `crm_deal_projects` | Luôn giả định 1–1 |
| Task CRM | `crm_tasks` | Nhầm `tasks` |
| Task SX/VC | `tasks` | Nhầm `crm_tasks` |
| Won | `is_won` + `autoCreateProject` / `autoDealWonProject` | Insert project bỏ helper |
| CRM routes | `routes/crm/routes/<cluster>.js` | Phình monolith |
| Stage fields | Cập nhật whitelist PUT `pipelines.js` | Chỉ ALTER DB |
| Roles | `helpers/adminRole.js` | So sánh role string rải rác |
| company scope | Filter `company_id` (trừ system admin) | Query all companies mặc định |

### Role

- `admin` không company_id → system admin
- `admin` + company_id → company admin
- `sales_admin` → admin-like, luôn company-scoped
- User thường → RPC permission

Helpers: `isAdminLike`, `isSystemAdmin`, `isCompanyScopedAdmin`, `isProductionStaff`, `isProductionAdmin`.

## 3. Backend patterns

- Import: `const { supabase } = require('../config/supabase')` — failover qua router.
- Route chỉ authz + orchestration; logic nặng trong `helpers/`.
- Lỗi JSON `{ error }` + status 4xx/5xx.
- `select('*')` → cột DB mới tự có trong response.
- External: `apiKeyAuth` + rate limit + `external_api_logs`.
- CRM shared: `routes/crm/shared/*` (`helpersBundle`, `requestScope`, `pipelineHelpers`…).

## 4. Frontend patterns

- API: `import api from '../lib/api'` (Axios + JWT interceptor).
- Auth: `useAuth()` từ `lib/auth.jsx` / auth context.
- Module routes: `/crm`, `/sx`, `/vc`, `/ketoan`, `/projects`, `/work`, `/drive`, `/knowledge`.
- Persist filter: `crmPipelineStorage`, `LS_SX`, `LS_ORG_REPORT`, `workshopPipelineStorage`.
- Lazy: `lazyWithRetry()`.
- Không redesign visual khi chỉ fix feature; giữ Tailwind pattern file hiện tại.
- Đồng bộ role helpers FE: `frontend/src/lib/adminRole.js`.

## 5. Migration

- File `database/NNN_ten.sql` — **không** có runner tự động.
- Ưu tiên idempotent.
- Sau đổi `crm_pipeline_stages` → whitelist PUT.
- Không commit dump `backend/uploads/_clone/`.

Tổng file SQL hiện có: **580** (danh sách mục 10).
