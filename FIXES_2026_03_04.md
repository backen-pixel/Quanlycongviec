## 🎨 FIX 1: Giao Diện Tạo Dự Án — Full Màn Hình

### Vấn Đề
Giao diện không fill đầy màn hình trình duyệt:
- Còn white space ở các cạnh
- Layout không thực sự fullscreen
- Header bị sticky gây layout issues

### Nguyên Nhân
```jsx
// ❌ SAI: negative margin không hoạt động
<div className="min-h-screen bg-... -mx-6 -my-6">
  <div className="sticky top-0"> // Gây issue
```

Vấn đề:
1. Element nằm trong `<main>` (có padding từ App.jsx)
2. `min-h-screen` = minimum height, không fill thực sự
3. Negative margin không override parent padding
4. `sticky` gây layout shift

### Giải Pháp
```jsx
// ✅ ĐÚNG: Fixed positioning + flex layout
<div className="fixed inset-0 flex flex-col bg-gradient-... overflow-hidden">
  {/* Header - fixed height */}
  <div className="flex-shrink-0 bg-white border-b">
    ...
  </div>
  
  {/* Scrollable content */}
  <div className="flex-1 overflow-y-auto">
    <div className="px-8 py-8">
      ... form content ...
    </div>
  </div>
</div>
```

**Kết Quả**:
✅ Thực sự fill 100% viewport
✅ Header stays at top (không sticky flickering)
✅ Content area scrolls internally
✅ Không có scroll bar doubled
✅ Hoạt động trên tất cả kích thước màn hình

### Kỹ Thuật Dùng

| Class | Mục Đích |
|-------|----------|
| `fixed inset-0` | Fill cả viewport (top/right/bottom/left = 0) |
| `flex flex-col` | Layout dọc (header + content) |
| `overflow-hidden` | Prevent double scrollbars |
| `flex-shrink-0` | Header giữ height cố định |
| `flex-1` | Content area grow hết remaining space |
| `overflow-y-auto` | Scroll chỉ trong content, không whole page |

## ⚡ FIX 2: Backend Deploy Chậm

### Vấn Đề
Backend deploy mất 4-7 phút, trong khi frontend chỉ 2-3 phút

### Nguyên Nhân
**render.yaml** dùng `npm install` trong buildCommand:
```yaml
buildCommand: npm install  # ❌ CHẬM
```

Tại sao chậm:
1. `npm install` download toàn bộ npm cache từ internet mỗi lần
2. Recalculate tất cả dependencies (không cache)
3. Chạy `npm audit` (security check, mất 30-60 giây)
4. Không dùng lock file tối ưu

### Giải Pháp
```yaml
# ❌ TRƯỚC
buildCommand: npm install

# ✅ SAU
buildCommand: npm ci --prefer-offline --no-audit
```

#### `npm ci` (Continuous Integration)
- Dùng `package-lock.json` → deterministic (exact versions)
- `--prefer-offline` → reuse cached packages
- `--no-audit` → skip unnecessary security checks (trust our deps)

**Kết Quả**:
```
⏱️  TRƯỚC: 4-7 phút
⏱️  SAU: 2-3 phút (50% nhanh hơn)
```

### Áp Dụng Cho Cả Backend & Frontend
```yaml
# Backend
buildCommand: npm ci --prefer-offline --no-audit

# Frontend
buildCommand: npm ci --prefer-offline --no-audit && npm run build
```
